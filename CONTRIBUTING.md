# Contributing Guide

Thank you for your interest in contributing! Here's how to get started.

## 📋 Guidelines

1. **Choose a Pattern** - Select a pattern folder and add your implementation
2. **Follow Structure** - Keep implementations organized by language or approach
3. **Add Documentation** - Include clear comments explaining the pattern
4. **Test Your Code** - Ensure examples work correctly
5. **Submit Changes** - Create a clear commit message

## 📝 Commit Message Format

```
[Pattern Name] Brief description

- What was added
- Key implementation details
```

Example:
```
[Singleton] Add Java implementation

- Thread-safe singleton using eager initialization
- Include usage example
```

## 🔍 Quality Standards

- Code should be clear and well-commented
- Include practical examples
- Follow language-specific conventions
- Add README.md in pattern folders if needed

## ❓ Questions?

Feel free to open an issue or discussion for clarifications.
